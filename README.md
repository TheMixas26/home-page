# О проекте

Это простенькая домашнаяя страница для моего браузера

## Режимы работы

У сайта есть два режима работы:

### I - обычный

В этом режиме сайт может загружаться откуда угодно, как и из локлаьной сети, так и, например, через GitHub Pages. 

На сайте будет календарь, простейший плеер музыки с одним треком и прочий *базовый* функционал.

### II - локальный

В этом режиме сайт проверяет ответ от API локального сервера (то есть ему требуется бэкенд). 

На сайте появляется возможность отмечать таски из Obsidian как выполенные и прослушивать любую локально скаченную музыку.

## Настройка:

Чтоб сайт мог работать во втором режиме, необходимо отредактировать config-файл.

```json
{
  "port": 5177,                     # Порт, на котором будет работать ваш бекэнд
  "musicDir": "~/Music",            # Путь к папке с музыкой
  "vaultDir": "~/Documents/Vault"   # Путь к вашим заметкам
}
```
